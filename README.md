# OpenRealism — The Long Room

An interactive, scroll-driven library walk through John Senior's **Thousand Good Books** list, built for the OpenRealism Good Books Program.

## What's inside

- **`Library Walk.dc.html`** — the whole experience: four 3D corridor halls (Nursery, School Days, Adolescence, Youth), 560 clickable titled spines, a page-turn book viewer, search (⌘K), floor-plan minimap, chapter rail, keyboard navigation, ambient room tone, and the *Faith & Reason* Great Books wing behind opening doors.
- **`books.json`** — the full book list parsed from *"Thousand Good Books by John Senior"* (title, author, age band).
- **`image-slot.js`** — drag-and-drop photo placeholders (hero plate + each hall's end alcove).
- **`_ds/`** — the Classical design system (tokens, stylesheet, component bundle) the page is built on.
- **`uploads/`** — OpenRealism logo and banner artwork.

## Viewing

The page is authored as a Design Component for the Claude design environment. To view outside it, open the project in that environment or serve the folder statically and open `Library Walk.dc.html` in a browser.
