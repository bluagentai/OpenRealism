# Great Books Agentic App

A beautiful, animated web application for teaching the Great Books Program and John Senior's 1000 Good Books Program with intelligent agents.

## Features

- **Beautiful UI with Animations**: Modern design with smooth transitions and animated elements
- **Responsive Layout**: Works on all device sizes
- **Agentic Learning**: AI-powered agents to enhance reading experience
- **Classical Education Focus**: Emphasis on great literature and philosophical texts
- **Music Integration**: Classical music references and links

## Technologies Used

- **Vue 3** with Vue Router for SPA navigation
- **Vite** for fast development server
- **Sass** for styling with global animations
- **GSAP** for advanced animations
- **Tailwind CSS** for utility-first styling
- **Font Awesome** for icons

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
4. Visit `http://localhost:3000`

## Key Pages

1. **Home**: Overview of the Great Books program with featured books
2. **Books**: Complete collection of Great Books with search and filtering
3. **Programs**: Details about the Great Books Program and John Senior's 1000 Good Books
4. **Agents**: Information about the AI learning agents that enhance the experience
